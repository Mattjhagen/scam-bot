"# Scam Call AI Bot" 
https://github.com/Mattjhagen/scam-bot

Let's build this to combat scammers by using a AI voice that will annoy the scammer and then send the transcript to the user for laughs

Also we would need a directory of known scam members to start with ,(eventually reports from users will also flag that caller) 

The idea is to keep the scanner on long enough taking to the AI bot while the backend can grab as much info as possible from the scammer. 

We can also record all calls so if one gets past the filter they can have the audio to give to their bank or whatever entity that they are pretending to be
